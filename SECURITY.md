# Security policy

This package decides whether a request comes from a genuine app on a genuine Apple device, so a bypass is a security problem.

## Report a problem

Report a vulnerability privately with [GitHub private vulnerability reporting](https://github.com/jewei/app-attest-php/security/advisories/new). Do not open a public issue for it.

Include the package version, the input that passes or fails (an attestation or an assertion, Base64), and what you expected. Remove user and session values from any client data.

You get an answer within 7 days. A fix comes in a patch release, with a GitHub security advisory.

## Supported versions

The latest minor release gets security fixes.
