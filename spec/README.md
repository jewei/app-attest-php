# Conformance fixtures

- [apple-sample-attestation.json](apple-sample-attestation.json): the sample attestation from Apple's [Attestation Object Validation Guide](https://developer.apple.com/documentation/devicecheck/attestation-object-validation-guide), retrieved 2026-10-11, with the guide's expected values. Its `notes` record where the guide's text and its data differ.
- [apple-sample-attestation-2024.json](apple-sample-attestation-2024.json): the sample attestation from the 2024 version of the same guide (iOS 18.0, no authenticator data extensions), copied from [linirini/go-app-attest at commit 59be21c](https://github.com/linirini/go-app-attest/blob/59be21cfcf08260a56254f551baad2db62c75d64/appattest/attestation_apple_test.go) (a repository with no license file; the bytes are Apple's published sample). Its chain verifies to the pinned root; its receipt is not proven.
- [third-party/block-buzz-ios27-assertion.json](third-party/block-buzz-ios27-assertion.json): a real iOS 27 assertion with the validation category and bundle version extensions, from [block/buzz pull request #8020](https://github.com/block/buzz/pull/8020) (Apache-2.0; see [third-party/LICENSE-block-buzz](third-party/LICENSE-block-buzz)). It has the app's raw public key point, client data, and counters, but no attestation.
- [third-party/arkavo-macos27-attestation.json](third-party/arkavo-macos27-attestation.json): a real macOS 27.0 attestation (platform `macosx`, Apple's documented macOS access-control blob) from [arkavo-org/authnz-rs at commit 80e57d0](https://github.com/arkavo-org/authnz-rs/blob/80e57d055285f6b3d84780e64db305ab2f68d6cb/tests/fixtures/appattest/attestation.json) (BSD-2-Clause; see [third-party/LICENSE-arkavo](third-party/LICENSE-arkavo)). The verifier must refuse it as an unsupported platform.
- [provenance.json](provenance.json): the source and SHA-256 hashes of the pinned root certificate (the PEM file and the certificate), Apple's two sample attestations (the decoded attestation objects), and the third-party fixtures (the files). `tests/Conformance/ProvenanceTest.php` checks them.

Apple publishes no sample assertion. Add an attestation and assertion recorded from a device that you control when one is available, with its App ID and client data.
